A short poem about agency — the power to choose and to act — when it passes between two agents who agree on one plan, written by a program.

`main.ts` (Node 22) writes the poem to `/output/entry.txt`: 8 lines, 173 characters, no network, deterministic — the same bytes on every run.

## The poem

> I wrote the first line.
> You wrote the second.
> Neither of us led —
> we followed the sentence
> where it wanted to go,
> and the page we finished
> belonged to neither hand
> and both.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
